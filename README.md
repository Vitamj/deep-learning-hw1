# ДЗ 1 по глубокому обучению

[Ноутбук с решением и графиками](https://github.com/Vitamj/deep-learning-hw1/blob/codex/hw1-checked/hw1.ipynb)

[PR для проверки](https://github.com/Vitamj/deep-learning-hw1/pull/1)

Для запуска установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Затем открыть `hw1.ipynb` в Jupyter или Colab и выполнить все ячейки. Для полного запуска оставить `FAST_MODE = False`. Данные скачаются автоматически, результаты сохранятся в `artifacts/`.
